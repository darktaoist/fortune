## PHASE 4 — Ralph Loop: 야간 무인 실행 (파일럿 성공 후)

### 대상 작업 고르는 기준 (셋 다 만족해야 함)
- 성공이 명령어로 검증됨 (build/grep/스크립트)
- DB 라이브 쓰기 없음 (Supabase 쓰기가 필요하면 `scripts/db/validate-*` 패턴처럼 dry-run만)
- 디자인 판단 없음 (색·레이아웃·카피 결정이 필요한 작업 제외)

### 세팅 (레포 루트)

`ralph/PROMPT.md`:
```markdown
너는 taounse2 레포에서 야간 자율 작업 중이다. 반드시 CLAUDE.md를 먼저 읽어라.

이번 반복에서 할 일:
1. .planning/ROADMAP.md에서 체크 안 된 항목 중 **첫 번째 하나만** 골라라.
2. 그 항목만 구현하라. 다른 항목은 건드리지 마라.
3. 검증: npm run i18n:check && npm run build — 실패하면 고치고, 두 번 실패하면
   해당 항목에 [BLOCKED: 사유] 를 적고 체크하지 말고 종료하라.
4. 성공 시: 항목을 체크(- [x])하고 git add -A && git commit -m "ralph: <항목명>"

금지 (위반 시 즉시 종료):
- rsync / ssh / pm2 / 배포 관련 일체
- .env 읽기·수정, Supabase 라이브 테이블 쓰기
- 디자인 토큰 변경 (배경 #0A0A0F, 골드 #C9A84C)
- package.json 의존성 추가
- ROADMAP에 없는 작업
```

`ralph/ralph.sh`:
```bash
#!/bin/bash
# 사용: caffeinate -i ./ralph/ralph.sh   (Mac 잠자기 방지 필수)
cd /Users/taoist/works/fortune
MAX=15   # 야간 안전 상한
for i in $(seq 1 $MAX); do
  # 프록시 생존 확인 — 죽었으면 즉시 중단 (ConnectionRefused 무한루프 방지)
  curl -s http://localhost:8787 >/dev/null || { echo "[ralph] headroom down, stop"; break; }
  # 남은 항목 없으면 종료
  grep -q -- '- \[ \]' .planning/ROADMAP.md || { echo "[ralph] all done"; break; }
  echo "===== iteration $i $(date) =====" >> ralph/ralph.log
  cat ralph/PROMPT.md | claude -p --dangerously-skip-permissions >> ralph/ralph.log 2>&1
  sleep 10
done
```

### 실행 절차 (저녁)
1. `git checkout -b ralph/night-$(date +%m%d)` — **main에서 직접 돌리지 않는다**
2. `headroom proxy` 생존 확인 → `caffeinate -i ./ralph/ralph.sh`
3. 아침 검수: `git log --oneline` + `ralph/ralph.log`의 [BLOCKED] 항목 + Claude in Chrome 라이브 확인 → 문제없는 커밋만 main 머지 → 사람이 배포

### 현실적 기대치
- 첫 밤은 3~5개 항목 수준의 작은 ROADMAP으로. 잘 되면 늘린다.
- `--dangerously-skip-permissions`는 이름 그대로 위험 — 반드시 브랜치 + 금지목록 + MAX 상한 3중 안전장치와 함께만.
- 토큰: 반복당 수만~수십만 토큰. 15회 상한이면 하룻밤 상당량 — 첫 실행 후 사용량 보고 상한 조정.

## PHASE 5 — (선택, 2주 뒤 평가) 테스트 도입으로 Ralph 강화

GSD/Ralph가 유효하다고 판단되면, Ralph의 검증 게이트를 "빌드 성공"에서 "테스트 통과"로 업그레이드:

1. `vitest` 도입 — 순수 함수부터: `server/utils/zh.ts`(번체 변환), `fortune-registry.ts`(프롬프트 레지스트리), 사주 계산 유틸
2. superpowers의 TDD 워크플로우를 이때 활성화 (테스트 없는 레포에선 무의미했던 부분)
3. `ralph/PROMPT.md` 게이트에 `npm test` 추가

이 단계까지 가면 "신규 운세 기능 1개를 밤새 TDD로" 그림이 실제로 성립한다.
