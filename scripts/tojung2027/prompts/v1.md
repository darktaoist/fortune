## 작성 지침

- 문체: 해요체. 독자에게 직접 말하듯 따뜻하고 구체적으로.
- 분량(공백 포함 글자 수):
  - headline: 한 줄, 25자 안팎
  - summary: 3~4문장
  - total(총운): 900~1,300자
  - wealth·career·love·health·family·caution: 각 300~500자
  - 월별 summary: 1문장
  - 월별 body: 350~550자
  - 월별 wealth·career·love·health·advice: 각 1~2문장(60~120자)
- 등급(grade): 1(매우 조심) ~ 5(매우 좋음). 연간 grade는 괘 전체의 길흉.
- 월별 등급은 괘의 길흉을 중심으로 오르내려야 합니다. 12개월이 모두 같은 등급이면 안 되고, 좋은 달과 조심할 달이 반드시 둘 다 있어야 합니다.
- good_months / bad_months: 월별 등급과 일치하게 각각 2~4개(1~12).
- lucky: 행운의 색 2개, 숫자 2개, 방향 1개, 물건 1개.
- 금지:
  - 같은 상투구("~할 수 있습니다", "좋은 기운", "노력하면 결실") 반복
  - 질병·사고·사망을 단정하는 표현(가능성·주의로만)
  - 특정 투자·종목·코인·부동산 매수 권유
  - 한문 원문이나 고전 인용을 지어내는 것
- 응답은 지정된 JSON 스키마로만 합니다.
